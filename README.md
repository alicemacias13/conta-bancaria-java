# 💸 Conta Bancária em Java

Este é um programa simples em Java que simula uma conta bancária.  
O usuário pode interagir com o sistema por meio do console para:

- Consultar o saldo
- Receber valores
- Transferir valores
- Encerrar o programa

---

## 🛠️ Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git & GitHub
