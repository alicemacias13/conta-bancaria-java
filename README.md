# 💸 Conta Bancária em Java

Este é um programa simples em Java que simula uma conta bancária.  
O usuário pode interagir com o sistema por meio do console para:

- Consultar o saldo
- Receber valores
- Transferir valores
- Encerrar o programa

---

## 🛠️ Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git & GitHub

---

## 🚀 Como executar o projeto no IntelliJ IDEA

1. Clone o repositório:
   
```bash
git clone https://github.com/alicemacias13/conta-bancaria-java

2. Abra o projeto no IntelliJ IDEA:

Vá em File > Open... e selecione a pasta do projeto

3. Compile e execute:

Clique com o botão direito no arquivo Main.java e selecione Run 'Main.main()'
